# Esercitazione finale in team Looker Studio

🎬 Analisi degli Oscar – Report interattivo per un nuovo produttore cinematografico

Durante questa Build Week, un cliente ambizioso ha richiesto una reportistica approfondita sui vincitori degli Oscar per trarre ispirazione e lanciarsi nel mondo della produzione cinematografica.  
Ci ha fornito un file .zip contenente numerosi file **CSV**, definendolo un “perfetto database”. In realtà, i dati erano disorganizzati, sporchi e non verificati.
Il nostro compito è stato quello di salvare il progetto, trasformando quel caos in un report interattivo e informativo.

📌 Obiettivi del progetto:

- Pulire e validare i dati forniti dal cliente  
- Strutturare i dataset in modo coerente e analizzabile  
- Caricare i dati in **Looker Studio**  
- Creare un report interattivo che analizzi almeno due categorie di premi  
- Evidenziare insight trasversali utili per decisioni strategiche nel settore cinematografico  

🛠 Strumenti utilizzati:

- **Looker Studio** per la visualizzazione interattiva  
- **Excel** per la preparazione e normalizzazione dei dati  
- **CSV** come formato di origine dei dati

# Final Team Project in Looker Studio

🎬 Oscars Analysis – Interactive Report for an Aspiring Film Producer

During this Build Week, an ambitious client requested an in-depth report on past Oscar winners to gain inspiration and break into the film production industry.  
He provided a .zip file full of **CSV** files, calling it a “perfect database.” In reality, the data was messy, unverified, and disorganized.
Our mission was to rescue the project and turn that chaos into a clear, interactive, and insightful report.

📌 Project Objectives:

- Clean and validate the data provided by the client  
- Structure the datasets in a coherent and analyzable format  
- Load the data into **Looker Studio**  
- Create an interactive report analyzing at least two award categories  
- Highlight cross-category insights useful for strategic decisions in the film industry  

🛠 Tools Used:

- **Looker Studio** for interactive visualization  
- **Excel** for data preparation and normalization  
- **CSV** as the original data format
